# DevOps Horizon

Blog technique professionnel DevOps basé sur **MkDocs Material**.

![MkDocs](https://img.shields.io/badge/MkDocs_Material-9.6-indigo)
![Python](https://img.shields.io/badge/Python-3.12-blue)
![Deploy](https://img.shields.io/badge/Cloudflare_Pages-Ready-brightgreen)

## Lancement local

```bash
pip install -r requirements.txt
mkdocs serve
```

## Déploiement Cloudflare Pages

**Build command :**
```
pip install -r requirements.txt && mkdocs build
```

**Output directory :** site

Prêt pour production. Design moderne, navigation instantanée, blog complet.
