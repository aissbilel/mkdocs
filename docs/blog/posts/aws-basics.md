# Tutoriel AWS : Les Services Essentiels 2026

## Services clés

- **EC2** : Machines virtuelles
- **EKS** : Kubernetes managé
- **S3** : Stockage objet
- **RDS** : Bases de données managées
- **Lambda** : Serverless

## CLI de base

```bash
aws ec2 describe-instances
aws s3 ls
aws eks update-kubeconfig --name my-cluster
```

AWS reste le leader du cloud public.
