# Tutoriel Linux : Le système de fichiers expliqué

Le système de fichiers Linux est organisé en une arborescence unique.

## Les répertoires essentiels

- `/` : Racine
- `/home` : Dossiers utilisateurs
- `/etc` : Fichiers de configuration
- `/var` : Logs et données variables
- `/usr` : Programmes utilisateur
- `/tmp` : Fichiers temporaires

## Commandes de base

```bash
ls -la          # Lister les fichiers
cd /etc         # Changer de répertoire
pwd             # Afficher le chemin courant
mkdir mon_dossier
rm -rf dossier    # Supprimer récursivement
```

Comprendre cette structure est la base de tout administrateur Linux.
