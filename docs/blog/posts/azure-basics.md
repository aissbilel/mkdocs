# Tutoriel Azure : Services Fondamentaux

## Ressources principales

- **AKS** : Kubernetes managé
- **App Service** : Applications web
- **Storage Account** : Stockage
- **Key Vault** : Secrets
- **Functions** : Serverless

## Azure CLI

```bash
az login
az aks get-credentials --resource-group rg --name myaks
az storage account list
```

Azure est très fort sur l'intégration Microsoft et l'IA.
